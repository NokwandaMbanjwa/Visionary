# Visionary
A platform that aims to tackle the effects of the digital divide in the academic space.
It addresses this concern by facilitating a connection between school learners and potential resource sponsors.
Grants access to learning resources needed by school learners to keep them on the same pace as other learners countrywide.

For advanced devices, the platform aims to mimic the usual e-commerce platform environment. For less advanced phones, requests can be made using USSD. There are currently three base users for this platform: School principals/teahcers, sponsors, and parents. There will be three portals to accomodate all identified primary users.
